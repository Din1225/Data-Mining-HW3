# 第 2 部分：主實驗、超參數與消融實驗

本資料夾接續 v1：2013 年資料用來選設定（驗證），2016 年是主要測試（1,480 人），2018 年是回測（532 人）。所有數字都由同一次執行的逐使用者結果重算，**沒有重新訓練任何模型**。

## 重新產生
```sh
python scripts/reproduce.py            # 先產生 results/（已跑過就略過）
# 食譜卡欄位消融（C 區；約 35 分鐘，CPU）
FOODCOM_DATA_DIR=data OMP_NUM_THREADS=16 conda run -n dm-hw3-enc python experiments/card_field_embeddings.py
FOODCOM_DATA_DIR=data OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 conda run -n dm-hw3 python experiments/card_field_ablation.py
# 產生所有表格與預測檔
FOODCOM_DATA_DIR=data conda run -n dm-hw3 python scripts/main_experiment_tables.py
```

## 怎麼讀（2016 測試）
1. **主方法排在中段。** 主方法命中 26 人（1.76%）。HR@10 最高的是 ALS + 熱門度，命中 33 人；NDCG@10 最高的是近兩年熱門榜（0.01161）。主方法的中位名次最好（6,793），代表它平均把答案排得比較前面，但前 10 名的命中沒有因此變多。
2. **差距都不大。** 單一方法的命中數本身就有約 ±10 人的運氣浮動，相當於 1,480 人、命中率約 1.8% 時的 95% 範圍。所以 20–33 人之間的差距目前不能下結論。正式的配對檢定交給第 3 部分。
3. **Ensemble 等於 ALS + 熱門度。** 2013 驗證集把「圖模型 + ALS 混合」的 ALS 比重選成 1.0，所以兩者每個人的名次完全相同。
4. **消融 A：兩年方向一致的零件。**
   - 拿掉「文字互動圖」（命中 −7／−3）或拿掉「熱門度」（−5／−2）都會變差，這兩個零件有貢獻。
   - 拿掉作者加分（+1／+1）或改用不含對齊損失的 ID（+3／+1）反而略好。
   - 只用近兩年熱門榜（+3／+2），比圖模型還好。
   - 拿掉學習 ID 在 2016 年 −2、2018 年 +3，方向不一致。
5. **消融 B：文字特徵階梯。**
   - 菜名 → 整張卡：命中 +0／+2，NDCG 兩年都上升。
   - 加互動圖：前 10 名幾乎不變，但中位名次大幅變好（12,853 → 6,873），推出的食譜種類從 355 降到 122。
6. **消融 C：拿掉食譜卡的欄位，前 10 名都沒有可量測的變化。** 所有差距都在 ±4 人以內。
   - 只用食譜卡時，拿掉食材兩年都略差（命中 −3／−1，NDCG 兩年都下降），食材可能有一點用。
   - 拿掉標籤的結果不一致：2016 年反而 +4，2018 年 NDCG 下降。
   - 加上互動圖之後，拿掉任一欄位的差距只剩 0 到 ±1 人，互動圖蓋過了卡片欄位的差異。
   - 原版卡片有 **40% 的食譜超過 64 tokens 被截斷**，標籤排在最後，最常被截掉。拿掉食材後沒有任何卡片被截斷，拿掉標籤後只有 8%。
7. **隨機種子。** 圖模型 3 個種子的命中數是 28.0 ± 1.7。大多數零件的差距和換種子的浮動差不多大。
8. **成本。** 主方法每次推薦 13.0 ms，熱門榜只要 0.01 ms。離線部分包括：MiniLM 把全部食譜編碼成向量約 13 分鐘（一次性）、建圖 5.6 秒、訓練 ID 69.8 秒；ALS 訓練 18.3 秒。

括號裡「／」前後依序是 2016 測試、2018 回測。

## 注意事項
- **數字來源。** 這些數字是在我們的 server（basic-2，CPU）跑出來的。隊友 Mac 上的參考值（`reference/table2_rankings.csv`）在少數列差 0–2 人，例如 2018 年主方法 6 vs 8，原因是 CPU 與 Apple GPU（MPS）編碼的數值差異。本資料夾的表格全部出自同一次執行，彼此一致；論文請統一使用同一次執行的結果。
- **使用者 kNN 沒有 2018 年結果。** 原程式 `run.py` 只跑驗證與測試。
- **選中值等於「關掉」的設定。** 驗證集有幾個選擇其實等於把某個零件關掉：食材基準裡使用者 kNN 的比重為 0、聯合作者 ALS 的作者強度為 0、ensemble 的 ALS 比重為 1。主實驗表沿用隊友原版，列的是「作者強度 1.0」的診斷版本，**不是**驗證集選出的設定；論文要註明。
- **消融版本沒有重新調權重。** 只看菜名、整張卡、加互動圖這幾個版本，沿用完整模型在驗證集選出的混合權重，沒有各自重調，對完整模型略有利。
- **Δ 都沒有做顯著性檢定。** 檢定交給第 3 部分。`experiments/evaluation.py` 已有配對 bootstrap、符號翻轉檢定與 Holm 校正，可以直接拿 `predictions/` 的名次來用。
- **食譜卡欄位消融（C 區）的做法。**
  - `experiments/card_field_embeddings.py` 用原版的 MiniLM 與相同設定重新編碼兩種卡片（CPU 各 7–9 分鐘）。
  - `experiments/card_field_ablation.py` 只把圖模型讀的「整張卡」向量換掉，沿用原版的混合權重重跑。卡片向量會同時影響卡片口味、互動圖、學習 ID 的對齊目標與口味一致度閘門。
  - 對照組用原版卡片重跑，2016 和 2018 的名次與原結果逐人完全相同，證明替換方式沒有改到其他東西。
  - 隊友的原始程式都沒有修改。
- 若第 1 部分的特徵分析指出其他值得測的欄位（例如描述、步驟、營養），可以用同樣兩支程式加做。
